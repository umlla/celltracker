# 🧬 细胞培养追踪系统

一个基于 Streamlit 的轻量级细胞培养管理工具，适合个人实验室或小团队使用。帮助实时追踪每一株细胞的传承、冻存、复苏与传代历史，自动计算倍增数（PD）并绘制生长曲线。

---

## ✨ 主要特点

- **即时保存**：所有操作直接写入数据库，无需手动存盘。
- **在养仪表盘**：一目了然查看所有在养细胞株总数，可按细胞株或自定义分组筛选。
- **批次与复苏绑定**：每次复苏创建独立批次，可关联冻存管，自动标记该管为“已复苏”。
- **自动 PD 计算**：基于 log2(收获/接种) 自动计算倍增数，支持原代初始 PD 和复苏接种数设置。
- **智能传代提醒**：每种细胞可设定默认传代间隔，看板自动用颜色标记剩余天数。
- **生长曲线可视化**：每个批次均可查看累计 PD 与细胞总数的双 Y 轴交互曲线，支持导出 CSV。
- **冻存管库存管理**：记录冻存位置、细胞数、PD 值（可留空），支持 9×9 虚拟冻存盒视图。
- **记录灵活修改**：可编辑或删除任意传代记录（自动重算 PD），也可直接修改冻存管信息。
- **细胞分组**：创建自定义细胞组，按组快速查看组内所有株的培养状态。
- **数据库备份与恢复**：一键下载完整数据库备份，也可上传恢复。
