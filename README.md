# 🧬 细胞培养追踪系统 v3.0

一个基于 **Streamlit** 的轻量级细胞培养管理工具，适合个人实验室或小团队使用。  
帮助实时追踪每一株细胞的传承、冻存、复苏与传代历史，自动计算倍增数（PD）并绘制生长曲线。

---

## ✨ 主要特点

- **即时保存**：所有操作直接写入 SQLite 数据库，无需手动存盘，断电不丢失。
- **在养仪表盘**：一目了然查看所有在养细胞株总数，可按细胞株或自定义分组筛选。
- **批次与复苏绑定**：每次复苏创建独立批次，可关联冻存管，自动标记该管为“已复苏”。
- **自动 PD 计算**：基于 `log2(收获/接种)` 自动计算倍增数，支持原代初始 PD 和复苏接种数设置，首次传代可参考批次初始值。
- **智能传代提醒**：每种细胞可设定默认传代间隔，看板用红/黄/绿底色标记剩余天数。
- **生长曲线可视化**：每个批次均可查看累计 PD 与细胞总数的双 Y 轴交互曲线，支持导出 CSV。
- **冻存管库存管理**：记录冻存位置、细胞数、PD 值（可留空），支持 9×9 虚拟冻存盒视图，已复苏冻存管可一键删除。
- **记录灵活修改**：可在传代历史中编辑或删除任意记录（自动重算累计 PD），也可搜索编辑冻存管信息。
- **细胞分组**：创建自定义细胞组，按组快速查看组内所有株的培养状态。
- **数据库备份与恢复**：一键下载完整数据库备份，也可上传恢复，再无数据丢失之忧。
- **局域网共享**：同一网络下同事可直接通过浏览器访问，支持校园网穿透（ZeroTier 等）。

## 📦 环境要求

- Python 3.9 及以上
- 依赖库：`streamlit`, `pandas`, `plotly`（其余为 Python 标准库）

安装依赖：

```bash
pip install streamlit pandas plotly
🚀 快速启动
将 cell_tracker.py 放入工作目录（或克隆本仓库）。

在终端进入该目录，运行：

bash
streamlit run cell_tracker.py
浏览器会自动打开 http://localhost:8501，系统会在同级目录自动生成数据库文件 cell_data.db。

局域网共享：启动后查看本机局域网 IP，同事只需访问 http://你的IP:8501（需同一网络）。若校园网隔离，推荐使用 ZeroTier 或 Tailscale 组建虚拟局域网。

📖 使用流程
添加细胞株：录入名称、类型（永生化/原代），可设置默认传代间隔。

录入冻存管：记录已有冻存库存，位置格式建议 罐名/架号/盒号/孔号（如 罐A/架1/盒1/A1）。

新建培养批次：每次复苏创建新批次，可选择绑定一支在库冻存管，系统自动标记并填入原始冻存日期。

记录传代：选择对应细胞株和批次，输入本次收获细胞数、种下盘数及每盘细胞数，代次默认自动+1，PD 即时计算。

日常查看：在“在养细胞”页面随时查看所有批次的盘数、细胞数、累计 PD 和传代提醒，可按组过滤。

生长曲线：展开任意批次，即可查看历史传代表格及动态曲线。

终止或编辑：对于污染、冻存殆尽等批次可“终止培养”；传代记录可编辑或删除（自动重算 PD）。

冻存盒视图：在“冻存管管理”页面查看 81 孔虚拟网格，可搜索、编辑或删除冻存管。

数据备份：侧边栏提供数据库下载与上传，定期保存至本地最安全。

🗄️ 数据库
系统使用 SQLite 数据库，文件名为 cell_data.db，位于脚本同目录。

首次运行时自动创建所有表结构。

数据库文件已在 .gitignore 中排除，不会上传至 GitHub，保护实验数据。
