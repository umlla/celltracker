# 🧬 CellTracker · 细胞培养追踪

记录细胞株、培养批次、传代、冻存和生长曲线的小工具，在浏览器里使用。

## 一、下载

1. 打开 <https://github.com/umlla/celltracker>
2. 点击绿色 **Code** 按钮 → **Download ZIP**
3. 解压到电脑上的任意文件夹，例如 `D:\CellTracker`

## 二、安装运行环境

第一次使用需要安装两个软件（只需装一次）：

- **Python 3.10 或更高版本**：<https://www.python.org/downloads/>  
  安装时务必勾选 **Add Python to PATH**
- **Node.js 20 或更高版本**：<https://nodejs.org/>  
  一路默认安装即可

安装完成后，最好重启一次电脑。

## 三、启动

1. 双击文件夹里的 **`start.bat`**
2. 第一次启动需要几分钟，请耐心等待
3. 浏览器会自动打开；如果没有打开，手动访问 **<http://127.0.0.1:18600>**
4. **黑色窗口不要关闭**，关闭窗口就会停止服务

以后每次使用，双击 `start.bat` 即可。

## 四、第一次使用

1. 添加细胞株
2. 新建培养批次（复苏）
3. 记录传代（可以单个录入，也可以按组批量录入）
4. 回到「在养细胞」查看培养状态、生长曲线和冻存情况
5. 需要冻存时，在「冻存状态」里点「＋ 新增冻存管」；存放位置可以以后再补

## 五、数据与备份

- 所有数据都保存在 `data` 文件夹里
- 不要手动删除或改名 `data` 文件夹
- 换电脑或重装系统时，把整个项目文件夹复制过去即可
- 也可以随时在「数据与工具」页面下载备份

## 六、常见问题

- **双击 `start.bat` 没反应**：确认 Python 和 Node.js 已经安装，再看黑色窗口里的提示
- **浏览器没有弹出**：手动打开 <http://127.0.0.1:18600>
- **提示端口被占用**：关闭占用该端口的程序后重新启动
- **想停止使用**：关闭黑色窗口即可
